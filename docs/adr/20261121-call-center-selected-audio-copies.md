Clear private state on identity or permission changes, preserve server authorization on every request, and keep publication/provider commands outside this flow. The native Dialog does not disable its default cancel footer from dismissible alone: this popup supplies native Buttons that also block footer dismissal while writes are pending, without modifying the shared Dialog.
