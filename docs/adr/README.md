# Registro de decisões arquiteturais

Use [0000-template.md](0000-template.md) para uma decisão relevante. Numere pela próxima sequência livre, registre contexto, decisão, consequências e evidências. Estados: Proposta, Aceita, Rejeitada ou Depreciada.

Não marcar uma proposta como aceita sem a decisão correspondente. Preserve os documentos anteriores; para alterar uma decisão aceita, escreva uma nova que indique qual decisão substitui.

## Decisões deste bootstrap

- [0010-manual-de-cultura-ciencia](0010-manual-de-cultura-ciencia.md): ciência por vínculo e versão, portal separado e arquivos privados.

- [0009-sla-publicado-na-criacao-autorizada](0009-sla-publicado-na-criacao-autorizada.md): aplicar SLA publicado na criação autorizada sem conceder gravação manual de condições; recusa de escrita preserva o formulário.

- [0008-abertura-interna-por-destinatario](0008-abertura-interna-por-destinatario.md): destinatários de outros departamentos da unidade e recuperação da abertura com nova autorização.

- [0007-visualizacao-responsiva-da-conversa](0007-visualizacao-responsiva-da-conversa.md): área de mensagens priorizada, editor adaptável e modo de ampliar conversa.

- [0001-governanca-operacional-init](0001-governanca-operacional-init.md): adoção do INIT solicitado pelo usuário.
- [0002-recibo-live-custodia-broker](0002-recibo-live-custodia-broker.md): custódia LIVE imutável e interoperabilidade com histórico, implementação local sem publicação.
- [0003-protecao-exclusao-historico-broker](0003-protecao-exclusao-historico-broker.md): proteção de exclusão anterior aos efeitos, preservando a custódia; autorização posterior de release e seus gates.
- [0004-chamados-destinatarios-projetos-escopo](0004-chamados-destinatarios-projetos-escopo.md): escolha de destinatário, projetos por responsável/participante e chamados encerrados em popup.
- [0005-encerramento-manual-sem-bloqueio-sla](0005-encerramento-manual-sem-bloqueio-sla.md): encerramento manual por usuários com acesso, sem requisitos extras e com tempos/SLA reais preservados.
